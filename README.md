# Mime Uddin Reba — Personal Portfolio

A personal portfolio website built with **HTML, CSS, and simple JavaScript**, following the Professional Integration GitHub Pages assignment from LaSalle College Montréal.

## Files

- `index.html` — the text and sections of the website
- `styles.css` — all colours, spacing, layout, and mobile styling
- `script.js` — the mobile navigation menu and automatic footer year
- `favicon.svg` — the small browser tab icon
- `.nojekyll` — tells GitHub Pages to publish the static site as-is

## How to publish on GitHub Pages

1. Sign in to GitHub as **Mime425**.
2. Visit <https://github.com/new> and create a **Public** repository named **Mime425.github.io**. The spelling must match your username (GitHub repository names are case-insensitive).
3. Open the repository, click **Add file → Upload files**.
4. Upload the **contents of this folder** (`index.html`, `styles.css`, `script.js`, `favicon.svg`, `.nojekyll`, and optionally `README.md`). Do not upload only the ZIP file or a folder containing the files.
5. Click **Commit changes** to save the files to `main`.
6. Open **Settings → Pages** in the repository.
7. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then **Save**.
8. Visit **https://mime425.github.io/** after GitHub finishes publishing. The first publication can take a few minutes.

## Edit your portfolio

- Open `index.html` to change your name, summary, school, skills, projects, and contact information.
- Open `styles.css` to change colours or other design settings.
- Change any project links in `index.html` when you add new repositories.
- To update the live website, commit the edited files to your GitHub repository.
